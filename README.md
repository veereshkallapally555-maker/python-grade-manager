Student Grade Checker

A simple Python program to calculate student grades, track pass/fail status, and generate a class summary.

🚀 Features

* **Interactive Inputs:** Prompt for student names and marks.
* **Automatic Grading:** Assigns grades (A, B, C, D, F) based on score thresholds.
* **Pass/Fail Tracking:** Calculates pass rates using a configurable passing mark.
* **Class Summary:** Displays total students, passed count, and class average score.
* **Helper Utility:** Demonstrates flexible argument handling with a total-calculation function (`*args`).

🛠️ Requirements

* **Python 3.x** installed on your system.

🏃 How to Run

1. Open your terminal or command prompt.
2. Navigate to the project folder.
3. Run the script:
   python grade_manager.py
