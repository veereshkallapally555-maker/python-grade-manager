# 🎓 Student Grade Checker

A Python command-line program that calculates student grades, determines pass/fail status, and generates a class performance summary.

The project demonstrates fundamental Python programming concepts including variables, data types, loops, conditional statements, functions, input validation, and basic calculations.

---

## ✨ Features

- 👨‍🎓 Accepts multiple student records
- 📝 Accepts student names and marks
- 📊 Calculates grades automatically
- ✅ Determines pass/fail status
- 👥 Counts passed and failed students
- 📈 Calculates average marks
- 🏆 Finds highest marks
- 📉 Finds lowest marks
- 🔍 Validates student input
- 🔢 Demonstrates Python `*args`
- 🖥️ Interactive command-line interface

---

## 📊 Grading System

| Marks | Grade |
|------:|:-----:|
| 90–100 | A |
| 75–89 | B |
| 60–74 | C |
| 35–59 | D |
| 0–34 | F |

**Pass Mark:** 35

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/veereshkallapally555-maker/python-grade-manager.git
```

### 2. Open the project

Open the project folder in VS Code.

### 3. Run the program

```bash
py grade_manager.py
```

### 4. Enter student details

Enter the number of students, followed by each student's name and marks.
